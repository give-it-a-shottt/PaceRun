- [주의] [확실] 같은 일을 하는 함수가 domain 안에 둘 있다: `speakSeconds`(runView.ts)와 `formatGapSeconds`(format.ts)는 "90 → 1분 30초, 60 → 1분, 45 → 초"로 같은 결과를 낸다. 하나만 고치면 표기가 갈라진다. — web/src/domain/runView.ts `speakSeconds`, web/src/domain/format.ts `formatGapSeconds` — 두 함수 본문을 diff에서 직접 읽어 비교(정수 초일 때 출력이 같음. 둘 다 format의 "표기를 하나로 맞춘다"는 목적과 겹침) — `speakSeconds`를 지우고 `formatGapSeconds`(필요하면 반올림 · 0 아래 처리만 `Math.max(0, Math.round())`로 감싸서)를 쓴다.
