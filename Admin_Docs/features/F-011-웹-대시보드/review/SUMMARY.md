## 최종 판정 (AI 위임 판정 — 사용자 확인 전)
- 수용할 지적과 이유: [주의] 3개 전부와 [제안] 가운데 아래 넷을 뺀 전부.
  - 오류 경계: 라우트 전체와 차트 · 지도 조각 둘레에 두었다. 조각을 받지 못하면 그 자리만 "불러오지 못했어요"와 [다시 시도]를 보여 준다.
  - 초를 말로 바꾸는 함수를 하나(`formatSecondsText`)로 합쳤다. 지표 자리 표시를 3개로 고쳤다.
  - 로그아웃: 서버에 닿지 못하면 로그아웃하지 못한 것으로 보고(로그인된 채로 둔다) 화면에 알린다. 서버만 쿠키를 지울 수 있기 때문이다.
  - 사이트를 열 때 서버에 닿지 못하면 로그인 화면이 아니라 "서버에 연결하지 못했어요"와 [다시 시도]를 보여 준다.
  - 쿠키 갱신이 401이면 0.3초 뒤에 한 번 더 해 본다(탭 두 개가 동시에 갱신한 경우).
  - 기준 날짜를 2000-01-01 ~ 오늘 안으로 맞추고, 더 갈 수 없으면 [이전]을 누를 수 없게 했다.
  - 지도 그림 주소를 하위 도메인 없는 주소로 바꿨다. `VITE_API_URL`은 같은 사이트일 때만 로그인이 유지된다고 README와 feature.md에 적었다.
  - "없는 기록" 판정을 `app/queryClient.ts`로 옮겨 테스트했고, 로그인 상태 테스트를 7개 더했다(닿지 못함 · 다시 시도 · 내 정보 읽기 실패 · 갱신 다시 해 보기 · 로그아웃 실패 · 거절).
  - 구조: 쪽 넘기기를 한 곳으로(`runPages`), 겹친 삼항과 긴 페이지 함수를 풀고, 작은 중복을 정리했다.
- 거절할 지적과 이유:
  - 글꼴 줄이기: 한글 글꼴을 쓰는 글자만 남기려면 글자 목록을 뽑아 다시 만드는 과정(도구 · 빌드 단계)이 필요하다. 내 PC에서만 띄우는 지금은 한 번 받으면 브라우저가 기억한다. 배포할 때 한다.
  - 지난번 기록을 최신 쪽부터 찾는 것: 서버에 "이 시각보다 앞의 같은 모드 한 건" 조회가 없다. 1인용이라 기록이 수천 건을 넘지 않고, 찾으면 멈춘다.
  - 테스트용 함수 내보내기: 모듈이 기억하는 로그인 상태를 테스트마다 비우는 데 쓴다. 빼려면 테스트마다 모듈을 새로 불러와야 해서 테스트가 더 읽기 어려워진다.
  - HTTP 상태 코드 상수 모으기: 쓰는 곳이 서너 군데이고 각각 뜻이 다른 판정(다시 시도할지 / 없는 기록인지 / 로그인이 풀렸는지)에 쓰인다. 숫자에 이름만 붙여 두었다.
