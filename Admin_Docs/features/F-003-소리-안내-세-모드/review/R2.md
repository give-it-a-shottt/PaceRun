## 지적 (있을 때)
- [신규] [제안] [확실] 재생기 정리가 한 try 안에서 pause → remove → release 순서로 이어져 있어, pause()가 던지면 remove · release가 불리지 않는다. 이 경우 네이티브 재생기(오디오 트랙)는 JS 객체가 수거될 때까지 남는다(평소 길에서는 생기지 않고, 재생기가 이미 망가진 오류 상황에서만) — `app/src/services/audioPlayers.ts` `disposePlayer` — 패킷 diff의 함수 본문 확인, 테스트("재생기 정리 중 오류를 던지지 않음")가 pause 실패 뒤에도 release가 불리는지 보는지는 확인하지 않음 — 단계마다 따로 try로 감싸거나(pause 실패와 상관없이 remove · release를 부른다), 최소한 release()는 finally에서 부른다. pause가 던질 때 release가 불리는지 확인하는 테스트 한 줄을 더한다.
