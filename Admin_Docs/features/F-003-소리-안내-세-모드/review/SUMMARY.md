## 최종 판정 (AI 위임 판정 — 사용자 확인 전)
- 수용할 지적과 이유: 제안 10개 가운데 7개. 모두 몇 줄로 끝나고, 소리 쪽은 한 번 놓치면 뛰는 중에 알아채기 어려워 테스트와 함께 고쳤다.
  - 재생기 정리를 단계마다 따로 보호했다(멈추기가 실패해도 놓아 준다). 러닝이 끝날 때 남은 15초 타이머를 지운다. 둘 다 테스트를 붙였다.
  - 페이스 차이 계산과 허용 범위를 `pace.ts`로 옮겨, 화면 값 쪽이 안내 판단 파일을 가져다 쓰지 않게 했다.
  - 목표값 0 테스트를 발걸음 박자 · 페이스메이커 · "달리기만 0초"까지 넓혔다.
  - feature.md에 발걸음 박자의 5분 안내가 계속되는 것과 문구 두 개를 적었다. 소리 파일 목록에는 범위가 어디와 같아야 하는지 주석을 달았다.
- 거절할 지적과 이유:
  - 안내 말하기의 겹친 오류 처리: 겹치는 것이 맞다. 다만 안내 때문에 계산 · 저장이 끊기면 러닝 기록이 망가지므로 바깥쪽 한 겹을 일부러 남겼다(주석에 이유를 적음).
  - '남은 러닝 닫기'가 복구 상태가 있을 때 닫지 않는 것: 복구 상태가 남아 있으면 새 러닝을 시작할 수 없게 막혀 있어(시작 전에 확인) 미완료 러닝이 둘이 될 길이 없다. 닫는 조건을 넓히면 오히려 복구해야 할 러닝을 닫을 위험이 생긴다.
  - "지금 구간" 확인 세 곳: 값은 한 번만 구한다(1차 반영). 남은 확인은 타입을 좁히려는 것이라 동작에 영향이 없다.
- 다음에 고칠 것: 실기기에서 소리를 들어 본 뒤(박자의 이음매, 음성과 박자가 겹칠 때) 필요하면 소리 파일을 다시 만든다. Q-009의 답에 따라 목표를 채운 뒤의 안내를 바꾼다.
