## 최종 판정 (AI 위임 판정 — 사용자 확인 전)
- 수용할 지적과 이유: [위험] 1개와 [주의] 8개 전부, [제안] 가운데 9개(복구 훅 · 진동 · 테마 훅 옮기기, 반복 코드, 알림 색, 글자 계산 중복, 딥링크로 시작할 때 남은 러닝 보호, GPS 되풀이 상한, 화면 꺼졌을 때 화면 갱신 건너뛰기). 끝내는 순간과 되살아나는 순간은 실기기에서만 드러나고 한 번 꼬이면 기록이 망가지므로 지금 고쳤다. 테스트는 진행 관리자 쪽(종료 중 경쟁, 동시 호출, 되살아남, 남은 위치 작업)을 채웠다.
- 거절할 지적과 이유:
  - 부르는 곳 없는 함수: 다음 기능(F-004 홈, F-006 기록)이 바로 쓴다. 지웠다 다시 만드는 것보다 둔다.
  - 위치 '항상 허용' 요청: 기획(ONB_01_001)에서 정한 내용이라 유지한다. 없어도 기록은 된다는 점은 기능 문서에 적었다.
  - "시작합니다" 시점: 카운트다운 숫자가 0이 되는 순간 러닝이 시작되며 말한다. 카운트다운 중에 말하면 아직 시작 전인데 시작했다고 듣게 된다.
  - GPS 안내: 시트가 열려 있으면 토스트가 가려져서, 신호를 잡을 때까지 시트 위에 띄운다. 기능 문서 "설계 의도와 다른 점"에 적었다.
  - 화면 흐름 테스트(권한 거부 · GPS 꺼짐 안내 창): 화면 테스트 도구가 없다. 에뮬레이터에서 확인한 범위를 기능 문서에 적었다.
- 다음에 고칠 것: Q-004(목표값 범위 · 기본값)는 사용자가 정하면 `runConfig.ts`의 값만 바꾸면 된다.
