- 실제 구조
  - 화면은 값을 계산하지 않는다. `describeRecords()` · `describeRunDetail()` · `describeSummary()`가 글자와 비율까지 만들어 주고 화면은 그리기만 한다(홈 · 계획과 같은 방식).
  - 막대 높이는 "이번 주에서 가장 큰 값(목표선이 있으면 그것까지 포함)"을 1로 본 비율이다. 10분을 못 채운 러닝의 거리도 막대와 합계 거리에는 넣고, 횟수에는 넣지 않는다. 그날 거리가 "0.0"으로 보일 만큼 짧으면(50m 미만) 뛰지 않은 날처럼 막대를 비운다.
  - 구간 표: 10m보다 짧은 구간은 페이스를 내지 않는다(값이 튄다). km 구간은 995m 이상이면 "1km"로 적고(GPS 오차), 끝까지 못 채운 마지막 구간은 "0.42km"처럼 적는다.
  - 러닝 상세와 완료 요약은 끝난 러닝만 보여 준다. 없는 번호나 끝나지 않은 러닝이면 "기록을 찾지 못했어요".
  - 작은 지도는 지도 없이 경로 선만 그린다(D-008). 위도 · 경도를 평면으로 옮길 때 경도에 cos(위도)를 곱해 옆으로 늘어나 보이지 않게 하고, 점이 200개를 넘으면 고르게 솎는다. 움직인 범위가 20m보다 작으면 그리지 않는다(제자리 GPS 흔들림).
  - 기록 탭은 화면이 보일 때 · 앱으로 돌아올 때 · 자정이 지날 때 다시 읽는다(`useRefreshOnFocus`). 목록은 보이는 줄만 그린다(FlatList).
  - 완료 요약의 이번 주 칸은 홈과 같은 계산(`weekProgress` · `weekCells`)을 쓴다.
- 설계 의도와 다른 점
  - 막대 차트의 목표선: 기획은 "이번 주 목표선"인데 주 목표는 횟수(주 3회)이고 막대는 거리라 단위가 맞지 않는다. 계획에 거리 목표가 있는 운동(페이스메이커)이 있으면 그 거리(여럿이면 가장 긴 것)를 긋고, 없으면 긋지 않는다 → Q-011.
  - 지난번 비교의 기준: 10분을 못 채운 기록은 "지난번"으로 삼지 않는다(시작하자마자 끝낸 기록 하나가 다음 비교를 흐린다). 이번 기록이 10분 미만이어도 비교 문구는 보여 준다 → Q-012. 차이가 1분 이상이면 "4분 33초"처럼 말한다.
  - 비교 상자의 둘째 줄은 `같은 인터벌 기준 · 6'12" → 6'05"`다(피그마는 "같은 인터벌 입문 기준" — 운동 이름. 비교는 기획대로 "같은 모드"끼리 한다).
  - 빈 상태 제목은 피그마의 "아직 기록이 없어요"를 썼다(기획 표는 "첫 러닝을 기록해 보세요"). (AI 위임 결정 — 나중에 만든 쪽인 피그마를 따랐다)
  - 러닝 상세의 지표는 3개다. 피그마의 네 번째 "평균 발걸음"은 뺐다(앱이 걸음 수를 재지 않는다).
  - 러닝 이름: 계획 없이 뛴 러닝은 모드 이름("인터벌" · "자유 러닝")이 제목이다.
  - 작은 지도의 바탕(길 무늬)은 없다. 상자는 피그마의 가로세로 비율을 지키며 폰 너비에 맞춘다.
  - 목표 글자는 점선 오른쪽 위에 두되, 일요일 막대가 그 자리까지 올라오면 한 줄 위로 올린다. 뛰지 않은 날은 막대 없이 바닥 표시만 그린다.
  - 기록 탭 빈 상태의 [10분만 뛰기]는 끝나지 않은 러닝이 있는지 먼저 보지 않는다(홈은 본다). 그런 러닝이 남아 있으면 카운트다운 뒤 "이미 기록 중인 러닝이 있어요"가 뜨고 홈으로 가서 복구 창이 열린다.
  - 피그마에 없는 것: "10분을 채우지 못해 횟수에는 들어가지 않았어요" 한 줄(상세 · 요약), 빈 상태의 GPS 안내와 [그냥 시작하기] · [취소], 읽지 못했을 때의 안내와 [다시 시도], "기록을 찾지 못했어요". 문구는 AI가 지었다.
- 에뮬레이터(Android API 37)에서 확인한 것 (2026-11-23)
  - 기록 탭: "이번 주 · 11월 16일 – 22일 · 3.0 km · 1회", 월요일 막대와 값, 최근 기록 5개(모드 배지 · 이름 · 날짜 · 거리 · 페이스)
  - 자정이 지나자 기록 탭이 "11월 23일 – 29일 · 0.0 km · 0회"로 바뀜
  - "페이스 유지" 템플릿을 적용하면 "목표 3 km" 점선이 생김
  - 러닝 상세: "지난번보다 페이스가 7초 빨라졌어요 / 같은 인터벌 기준 · 6'12" → 6'05"", 날짜와 시각 범위, 지표 3개
  - 인터벌을 3분 뛰고 끝냄 → 완료 요약에 비교 상자, 지표 3개, "10분을 채우지 못해…", 경로 선(출발 · 도착 표시), 이번 주 칸 → [확인] → 홈 → 기록 탭 목록 맨 위에 그 러닝 → 상세에 경로와 구간 표(달리기 1:00 · 걷기 1:30 …)
- 확인하지 못한 것: 빈 상태 화면과 거기서 [10분만 뛰기], 인정된 러닝의 형광펜 칠하기, 다크, 기록이 수백 개일 때, 실제로 뛴 구불구불한 경로(에뮬레이터는 곧은 선)
