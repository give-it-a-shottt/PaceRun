## 지적 (있을 때)
- [신규] [제안] [추정] 알림 시간 시트에서 시 · 분 [+]/[−]를 한 번 누를 때마다 `update('reminderTime', …)`로 DB에 저장하고, 루트 레이아웃의 effect가 `reminderTime`이 바뀔 때마다 `syncReminder`를 다시 불러 알림을 다시 예약한다. 원하는 시각까지 여러 번 누르면 저장 · 예약이 누른 횟수만큼 반복된다(앞 예약이 끝나기 전에 다음 예약이 시작될 수 있음) — 위치: `components/settings/ReminderSheet.tsx` `change` → `ReminderFields` 의 `setClock`, `app/_layout.tsx` 의 `useEffect([status, reminderTime])` — 확인한 범위: ReminderSheet · ReminderFields · _layout.tsx의 syncReminder 부분은 읽음, `services/reminder.ts`의 `syncReminder`(취소 후 다시 예약하는지, 겹쳐 불려도 안전한지)와 `stepMinute`의 한 칸 크기는 열지 않음 — `syncReminder`가 겹쳐 불릴 때 예약이 하나만 남는지 확인하면 [확실]이 된다. 고치는 방법: 값 저장은 지금처럼 바로 하되 `syncReminder` 호출을 짧게 디바운스하거나, 진행 중인 예약이 끝난 뒤 마지막 값으로 한 번만 다시 예약하게 한다(누르는 횟수가 적어 지금 그대로 두어도 된다).
