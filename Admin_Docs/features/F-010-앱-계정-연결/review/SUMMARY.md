## 최종 판정 (AI 위임 판정 — 사용자 확인 전)
- 수용할 지적과 이유: 전부.
  - 로그아웃의 순서: 기다리는 일(보관함 · 서버)을 하기 전에 한 번에 판 번호를 올리고 · 액세스 토큰을 버리고 · 상태를 "로그아웃됨"으로 바꾼다. 그래서 보관함을 지우는 사이에 시작되는 요청 · 갱신은 "로그인돼 있지 않다"로 바로 막힌다. 테스트 1개(지우기를 붙잡아 둔 채 요청을 보내는 순서).
  - 내려받은 기록의 번호가 달라고 한 번호와 다르면 넣지 않는다. 테스트 1개.
  - 로그아웃한 상태에는 동기화의 실패 까닭을 적지 않는다(만료 포함). 테스트 1개.
  - 보관함 읽기 실패 테스트 1개.
- 거절할 지적과 이유: 없음.
- 다음에 고칠 것: Q-006의 답에 따라 서버 상한을 넘는 기록의 처리를 바꾼다.
- 알려 둘 것: 로그아웃과 겹치는 순간은 1차 · 2차 · 3차에 걸쳐 네 군데가 나왔고 모두 테스트로 순서를 만들어 확인했다(서버에 다녀오는 사이 / 보관함에 넣는 사이 / 요청의 답을 기다리는 사이 / 보관함을 지우는 사이). 3차의 수정은 리뷰어가 권한 방법 그대로이고, 다시 리뷰하지는 않았다.
