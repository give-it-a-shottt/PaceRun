## 최종 판정 (AI 위임 판정 — 사용자 확인 전)
- 수용할 지적과 이유: [주의] 2개와 [제안] 10개. 동시 갱신 문제는 웹(탭 여러 개)을 붙이면 실제로 겪을 일이라 지금 고쳤다. 로그아웃한 토큰은 "표시"가 아니라 "삭제"로 바꿔 오탐을 없앴고, 토큰을 새로 줄 때 낡은 줄을 지운다.
- 거절할 지적과 이유:
  - 500 응답의 CORS 헤더: 웹은 어차피 "잠시 뒤 다시 시도" 한 가지로 안내한다. 미들웨어 순서를 바꾸는 것은 얻는 것에 비해 건드리는 범위가 크다. 웹(F-011)에서 문제가 되면 그때 고친다.
  - `httpx2`: 확인했다. Starlette가 테스트 클라이언트용으로 직접 안내하는 패키지이고 관리 주체가 pydantic이다. 그대로 쓴다.
- 다음에 고칠 것: 로그인 시도 횟수 제한(Q-002, 배포할 때).
