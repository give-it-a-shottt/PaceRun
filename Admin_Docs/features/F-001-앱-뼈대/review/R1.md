## 지적 (있을 때)
- [주의] [확실] 설정 저장 실패 시 되돌리기가 다른 키의 변경까지 덮어쓴다 — app/src/state/settingsStore.ts `update` — 패킷 diff 전체를 직접 읽음. 두 번 연달아 `update`를 부르면 두 번째 호출의 `previous`에는 첫 번째 값이 이미 들어 있다. 첫 번째 저장이 실패하면 `set({ settings: previous })`가 첫 호출 이전 스냅샷으로 되돌려, 그 사이 성공한 다른 변경도 화면에서 사라진다(DB에는 남아 있어 화면과 DB가 어긋남) — 되돌릴 때 전체 객체가 아니라 해당 키만 되돌린다: `set((s) => ({ settings: { ...s.settings, [key]: previous[key] }, error: '…' }))`
