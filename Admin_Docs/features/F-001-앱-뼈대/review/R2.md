## 지적 (있을 때)
- [주의] [확실] 아이콘을 `phosphor-react-native` 묶음 입구(index)에서 가져와서 아이콘 1,512개(각각 굵기 6종 SVG 경로 포함)가 전부 JS 번들에 들어간다. Expo SDK 58의 Metro 트리 셰이킹은 기본으로 꺼져 있다 — 위치: `app/src/components/DockBar.tsx`(HouseIcon 등 4개 import), `app/src/components/TopBar.tsx`(CaretLeftIcon import). `Button.tsx`는 `import type`이라 해당 없음 — 확인한 범위: diff의 import 문, `node_modules/phosphor-react-native/src/index.tsx`(`export *` 1,513줄), `node_modules/expo/node_modules/@expo/cli/build/src/start/server/middleware/metroOptions.js`(트리 셰이킹은 production에서 `EXPO_UNSTABLE_METRO_OPTIMIZE_GRAPH`와 `EXPO_UNSTABLE_TREE_SHAKING` 둘 다 켜야 함, 둘 다 기본 false), app 폴더에 metro.config·.env 없음. 실제 번들 크기는 재 보지 않았다(참고: `lib/commonjs/icons` 폴더가 압축 전 5.0MB) — 고치는 방법: 패키지가 열어 둔 개별 경로로 가져온다. 예: `import { HouseIcon } from 'phosphor-react-native/src/icons/House'`(package.json `exports`의 `./src/icons/*`). 앞으로 아이콘을 쓰는 모든 화면에 같은 규칙을 적용하도록 공용 아이콘 모음 파일 하나(예: `src/components/icons.ts`)에서 개별 경로로 다시 내보내면 실수를 줄인다.
- [제안] [확실] 템플릿에서 남은 네이티브 패키지 가운데 `src`에서 쓰지 않는 것이 있다: `@expo/ui`, `expo-glass-effect`, `expo-symbols`, `expo-web-browser`, `expo-device`, 그리고 웹을 뺐는데 남은 `react-dom`·`react-native-web`. 개발 빌드(D-001)에서는 쓰지 않아도 네이티브 코드가 APK에 들어간다 — 위치: `app/package.json` dependencies — 확인한 범위: `app/src` 전체에 위 패키지 import가 없음(Grep). expo-router 등 다른 패키지가 내부에서 필요로 하는지는 확인하지 않았다 — 고치는 방법: `npx expo install --check`와 `npx expo-doctor`로 필수 여부를 본 뒤 필요 없는 것만 지운다. 급하지 않다.
