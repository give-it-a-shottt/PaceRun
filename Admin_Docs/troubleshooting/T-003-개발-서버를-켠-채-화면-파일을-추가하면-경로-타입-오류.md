# T-003 개발 서버를 켠 채 화면 파일을 추가하면 경로 타입 오류

## 한눈에 보기 (코드 몰라도 OK)
상태: [통과]
무슨 문제였나: 새 화면 파일(`onboarding/index.tsx`)을 추가했더니, 맞는 주소 `/onboarding`으로 이동하는 코드가 타입 검사에서 "없는 주소"라고 나왔다.
어떻게 해결했나: 개발 서버(Metro)를 껐다 다시 켰다. 주소 목록 파일이 처음부터 다시 만들어지면서 맞게 바뀌었다.

## 개발자 상세
- 증상: `npx tsc --noEmit`에서 `Type '"/onboarding"' is not assignable to …`. 만들어진 `app/.expo/types/router.d.ts`에 주소가 `/onboarding`이 아니라 `/onboarding/index`로 들어 있었다.
- 원인: expo-router는 화면 파일을 보고 주소 목록 타입(`.expo/types/router.d.ts`)을 만든다. 윈도우에서 개발 서버가 켜져 있는 동안 새로 생긴 파일은 경로가 역슬래시(`\`)로 전달되어, 끝의 `/index`를 떼어 내는 처리가 먹지 않는다. 서버를 시작할 때 한꺼번에 만드는 목록은 맞게 나온다.
- 해결: 개발 서버를 다시 시작한다. `.expo/`는 git에 올리지 않는 만들어진 파일이라 손으로 고쳐도 다음에 다시 덮어쓰인다.
- 재발 방지: 화면(라우트) 파일을 새로 만든 뒤 타입 오류가 주소에서 나면 코드를 고치기 전에 개발 서버부터 다시 켠다.
