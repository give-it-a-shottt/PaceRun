# T-004 에뮬레이터가 빈 화면에서 멈추고 시계가 건너뛴다

## 한눈에 보기 (코드 몰라도 OK)
상태: [통과]
무슨 문제였나: 에뮬레이터에서 앱이 흰 화면만 보이거나 화면이 굳었고, 그 사이 진행 중이던 러닝의 경과 시간이 2시간 넘게 늘어나 있었다.
어떻게 해결했나: 원인이 둘이었다. 흰 화면은 개발 서버(Metro)가 멈춰 있어서였고(다시 켬), 굳는 화면과 시계 건너뜀은 오래 켜 둔 에뮬레이터 탓이었다(다시 켬).

## 개발자 상세
- 증상 1: 앱을 열면 흰 화면에서 멈춤. 기기 로그에는 오류가 없다. 개발 서버의 `/status`는 200인데 화면 묶음(bundle) · 목록(manifest) 요청은 답이 없다.
  - 원인: 개발 서버가 파일 감시 상태가 꼬인 채 멈춰 있었다(직전에 한 번의 묶음에 86초가 걸린 기록이 있었다).
  - 해결: 개발 서버 프로세스를 끝내고 다시 켠다. 태스크만 멈추면 node 프로세스가 남아 포트를 계속 잡고 있으므로, 8081 포트를 잡은 프로세스가 expo 개발 서버인지 확인하고 끝낸다.
- 증상 2: 화면 캡처가 같은 장면에서 바뀌지 않고, 상태 표시줄의 시계와 `adb shell date`가 서로 다르다. 조금 뒤 기기 시계가 2시간 17분 건너뛰었다.
  - 원인: 여러 시간 켜 둔 에뮬레이터가 멈칫거리다 한꺼번에 시계를 맞춘 것으로 보인다(확인하지 못한 추정).
  - 해결: 에뮬레이터를 끄고 다시 켠다.
  - 이때 드러난 것: 러닝의 경과 시간은 폰 시계의 차이로 계산하므로(D-005) 시계가 건너뛰면 경과 시간도 그만큼 늘어난다. 실제 폰에서는 뛰는 중에 시계를 손으로 바꿀 때만 생긴다. D-005 "결과로 생기는 제약 2"에 적었다.
- 증상 3: 앱 데이터를 지운 뒤 처음 켜면 "근처 기기를 찾도록 허용" 창이 뜬다.
  - 원인: 개발용 빌드에 들어 있는 개발 도구(expo-dev-launcher)가 같은 네트워크의 개발 서버를 찾으려고 요청하는 권한이다(안드로이드 17에서 새로 생긴 로컬 네트워크 권한). 배포용 빌드에는 없다.
- 재발 방지: 화면 확인 전에 개발 서버의 목록 요청(`curl -H "expo-platform: android" http://127.0.0.1:8081/`)이 바로 답하는지 본다. 에뮬레이터를 오래 켜 뒀으면 확인 전에 다시 켠다.
- 관련: F-003, D-005
