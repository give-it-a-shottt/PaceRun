# D-008 앱의 작은 지도는 경로 선만 그린다

## 한눈에 보기 (코드 몰라도 OK)
상태: [보완]
무엇을: 앱의 완료 요약 · 러닝 상세에 있는 '작은 지도'는 길 · 건물 없이 내가 뛴 경로 선만 그린다. 웹은 실제 지도(OpenStreetMap) 위에 그린다. (AI 위임 결정 — 임시. Q-001이 열려 있음)
왜: 안드로이드 앱에 실제 지도를 넣으려면 Google Maps 키를 본인 계정으로 발급해야 하는데, 그건 사용자가 정하고 직접 해야 하는 일이다.

## 개발자 상세
- 구현: react-native-svg로 위치 점을 화면 좌표로 바꿔 선으로 그린다. 시작 · 끝 표시만 있다.
- 웹: Leaflet + OpenStreetMap 타일(키 불필요).

| 후보 | 장점 | 단점 |
|---|---|---|
| A. 경로 선만 (선택, 임시) | 키 · 계정 불필요, 가벼움 | 어디를 뛰었는지 주변이 안 보임 |
| B. react-native-maps + Google Maps | 익숙한 지도 | API 키(비밀값) 발급 · 관리 필요 |
| C. MapLibre + 공개 타일 | 키 없이 실제 지도 | 네이티브 설정 추가, 타일 서버 사용 조건 확인 필요 |

- 이 결정을 바꿔야 하는 조건: Q-001에서 사용자가 실제 지도를 넣기로 하면 B 또는 C로 바꾼다. 경로 좌표 변환 함수는 그대로 쓸 수 있다.
