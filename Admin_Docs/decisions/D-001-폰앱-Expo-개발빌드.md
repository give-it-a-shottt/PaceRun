# D-001 폰 앱은 React Native(Expo 개발 빌드), 워치 앱 없음, 웹은 React로 따로

## 한눈에 보기 (코드 몰라도 OK)
상태: [통과]
무엇을: 워치 앱은 만들지 않고 폰 앱으로 간다. 폰 앱은 React Native(Expo, 개발 빌드)로, 웹 대시보드는 React로 따로 만든다.
왜: 워치가 갤럭시 워치3(Tizen)라서 워치 앱은 빼기로 했다. (사용자 확인 — 2026-11-22 사용자 말)

## 개발자 상세
- 상황: 러닝 중 안내를 어디서 낼지 정해야 했다. 가진 워치는 Tizen이라 Wear OS 앱을 쓸 수 없다.
- 결정: 안드로이드 폰 앱 하나. 화면 꺼진 상태의 GPS · 알림 버튼 같은 네이티브 기능이 필요해서 Expo Go가 아니라 개발 빌드를 쓴다.
- 결과로 생기는 제약: 앱을 실행하려면 네이티브 빌드가 필요하다(`npx expo run:android` 또는 EAS 빌드). 네이티브 코드를 넣은 라이브러리를 추가할 때마다 다시 빌드한다.
- 이 결정을 바꿔야 하는 조건: Wear OS 워치로 바꾸거나, 폰을 두고 뛰고 싶어질 때.
