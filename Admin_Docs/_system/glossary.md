# 용어집

| 용어 | 쉬운 말 |
|---|---|
| 개발 빌드 | Expo Go 대신, 내 앱 전용으로 한 번 빌드해 폰에 설치하는 개발용 앱. 화면 꺼진 상태의 GPS처럼 기기 깊숙한 기능을 쓸 수 있다 |
| 포그라운드 서비스 | 안드로이드가 "이 앱은 지금 일하는 중"이라고 알림을 띄워 두고, 화면이 꺼져도 멈추지 않게 해 주는 장치 |
| JWT | 서버가 서명해 준 출입증. 서버는 서명만 확인하면 누구인지 알 수 있다 |
| 액세스 토큰 | 요청마다 내는 짧은 출입증(30분) |
| 리프레시 토큰 | 출입증이 만료되면 새로 받을 때 내는 교환권(30일) |
| 해시 | 원래 값을 되돌릴 수 없게 바꾼 지문. 비밀번호 · 리프레시 토큰은 지문만 저장한다 |
| 페이스 | 1km를 뛰는 데 걸리는 시간. 6'08"/km = 1km에 6분 8초 |
| 케이던스 | 발걸음 박자. 분당 걸음 수(spm) |
| 인터벌 | 달리기와 걷기를 번갈아 반복하는 운동 |
| 페이스메이커 | 목표 페이스보다 빠른지 느린지 알려 주는 모드 |
| SQLite | 폰 안에 파일 하나로 들어 있는 작은 DB |
| 순수 함수 | 같은 값을 넣으면 항상 같은 값이 나오고, 바깥 것을 건드리지 않는 함수. 기기 없이 테스트할 수 있다 |
| JSONB | Postgres에서 목록 · 묶음 데이터를 한 칸에 통째로 넣는 칸 종류 |
| 동기화 | 폰의 기록을 서버로 올리고, 서버의 기록을 폰으로 내려받아 둘을 맞추는 일 |
